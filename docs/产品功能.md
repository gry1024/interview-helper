# 产品功能

左侧三个入口：**模拟面试** / **面试复盘** / **JD/面经 库**。

形态是两个 Agent：

- **面试官**：系统提示 = 真实 JD + 面经总结的岗位本质（大模型公司技术骨干）。可调：检索面经库、核对仓库、面经手撕。
- **老师**：另一套提示词。学生点「求助老师」时，只针对**当前这一问**给旁边小抄；不追问、不评分、不推进面试。需要对照实现时才调 `code_inspect`。学生仍须用自己的话回答面试官。

一场只面一个项目。

## 1. 模拟面试

### 输入

只要：**项目陈述**、**GitHub 仓库**、**岗位**（`llm-algo` / `agent` / `rag`）。不解析整份简历。一次一个项目。岗位枚举以 `app/jd/roles.json` 为准。

### 开始前

并行：

- 浅 clone 仓库，供 tool 检索。全文不灌进面试官上下文。
- 加载该岗位的 **岗位本质 / 骨干前置知识**（只来自库内真实 JD+面经）。
- **定话题方向**：根据岗位选定面试官专家agent。开场前根据项目陈述预设若干话题方向，贯穿整场。一场只面这一个项目。

### 进行中

整屏只有对话。每条回答正下方打印思考，不给总评、不给建议。

```
[左] 面试官提问
[右] 用户回答
     └─ 正下方思考（流式）
            · 评价这句
            · 是否检索面经 / 核对仓库 / 打开手撕
            · 本话题继续挖 / 切换到下一条已定方向
     思考结束 → 下一问出现在左侧
```

思考只服务「把这个项目挖深」：继续还是换题、要不要对仓库、当前话题要不要按面经出手撕。挖到不能再挖为止。

底部：**发送**、**求助老师**、**结束面试**。用户点结束才停。求助不占一轮面试、不替学生交卷。

### 求助老师

面试进行中可点。老师 Agent 读最近对话和当前面试官那一问，给出短提示（须带「请用自己的话回答面试官」）。禁止预告后续方向、禁止把提示写成下一问。查仓库时不在提示里写文件名行号。

提示出现在对话里，与面试官气泡分开。次数写入本场记录；结束报告必须点名求助了几次、卡在哪一问。**不得因为小抄里有正确答案就把人抬成「真懂」。**

### 下一问

开场方向是宪法。面中不发明新主线。

1. 根据岗位选定面试官专家agent。开场前根据项目陈述预设若干话题方向，贯穿整场。一场只面这一个项目。
2. 每答之后：评价 → 检索面经/查仓库/考核手撕 → 判断本话题继续深挖，或切换方向提问。
3. 同一方向可以很多轮，一步步引到挖不动为止。
4. 口头提问不引用仓库文件名和行号，不劝用户点结束

仓库在面中用于核对与决定怎么引。手撕用于核实「会不会写」，不是另开刷题。

### 点结束后

对话左移；右侧综合报告——这里才出现：

- 总评
- 岗位匹配（这类岗真正在筛什么，和你这个项目的距离）
- 知识掌握建议（哪一块还不够）
- 项目改良建议（成熟度、贴岗、前沿性上能改什么）

报告阶段仍可 call 代码核对：对照**代码事实 vs 求职者表述**。求助记录一并进入快照。

全文（每轮问答、每轮思考含 tool、老师提示、整份报告）原样写入复盘，一个字不省略。

## 2. 面试复盘

点开一条 = 结束页原样（左对话右报告，两栏各自滚动）。展示不重写。

## 3. JD 库（数据是产品的护城河）

页面同时展示两类网上真实样本，禁止编造。展示前会丢掉明确面向硕博、不含本科的条目；小红书来源排在前面。

- **JD**：公司、岗位、职责与要求、来源
- **面经**：公司、岗位、原文或可核对摘录、来源

**信息源**：小红书为主，兼招聘平台与公司官网。「怎么问、怎么追」（小红书采集借用开源爬虫工具 [cv-cat/Spider_XHS](https://github.com/cv-cat/Spider_XHS)。）

库的第二用途：离线总结进面试官系统提示+检索数据库。JD：「考察什么能力」；面经：「怎么问、怎么追」。这份数据决定我们和 ChatGPT、和市面 100% 通用面试助手的区分。

## 4. 面试官的三个 Tool（老师只用核对仓库）

**检索面经** `search_library`：仅面试官。每轮按当前话题在已采集 JD/面经上检索，用相关原问改写下一问；条数不固定，没有相关命中就空着。

**代码核对** `code_inspect`：面试官思考、老师求助、结束后报告都可启用。核表述与仓库是否一致。不把路径行号念给学生。

**手撕代码** `code_exercise`：仅面试官。聊到面经常考的实现时弹出编辑器。题只从 `code_exercises.json` 取。老师不调此 tool。报告阶段不调手撕与检索。

## 5. 刻意不做

产品只有三个入口：模拟面试、面试复盘、JD/面经库。不在界面或 Agent 里做下列事项。

- **整份简历优化**：收所有岗位、所有阶段，不够定制
- **全岗位通用面试官**：必须按岗位用 JD+面经定制；通用人设问不深
- **通用题库 / 笔试 / 八股**：不是本质；基础题有大把优秀刷题平台
- **多项目一起面、实习经历拷问**：不一定有仓库，也稀释单项目深挖
- **论文线、语音视频、登录注册**：未来功能标配，初期不做。
